# symbols.woff2

`symbols.woff2` 는 Nerd Fonts v3.5.1 의 Symbols Nerd Font 에서 `icons.ts` 가 쓰는 glyph 만 뽑은 것이다(`scripts/subset-symbols.sh`). 담긴 glyph 는 모두 Codicons 의 것이다.
